# Claude Code

This repo is Lotl. Follow `AGENTS.md` as the source of truth. Skills live in `skills/`.

## Boot

1. `lotl_ready`
2. `list_roblox_studios` and pass `studio_id` on every official Roblox Studio tool
3. `lotl_studio` method `context`

MCP servers come from project `.mcp.json` (`lotl` and `Roblox_Studio`). Approve them once. If `pluginLive` is false, restart Roblox Studio after `lotl plugin install`.

Do not add a second Studio MCP. Computer Use is last resort, never for DataModel or files.
